# Random Walk Simulation

## Overview

This project is a Python simulation of a one-dimensional random walk.
At each step, the position changes by either +1 or -1 with equal probability. The aim is to explore how random processes behave when repeated many times.
This project is the first stage of a larger project exploring Monte Carlo simulation and its applications to quantitative finance.

## Questions I Want to Investigate

* What is the average final position across many simulations?
* How does the distribution of final positions change as the number of steps increases?
* How does the standard deviation change as the number of steps increases?
* How closely do the simulation results agree with mathematical predictions?

## Future Development

The random walk will be used as a foundation for learning about probability and Monte Carlo simulation. The eventual goal is to apply these ideas to financial modelling and options pricing.
